# MKS — книга, лаборатория и открытые инструменты

**MKS** — это не «проект про датчики». Это исследовательская лаборатория вокруг
книги **«Многомерный Кристалл Сознания»**. Датчики, протоколы, ESP32, Home
Assistant и измерения появились потому, что для книги нужно было проверить
утверждения о сне, среде и восприятии — а не просто собрать красивую таблицу.

## Зачем это книге

Книга говорит о сознании, сне, свете, воздухе и восприятии. Мы не хотим писать
об этом только по литературе, поэтому дом стал площадкой:

- **сон** — SleepDot/Sleepace: стадии, пульс, дыхание, движение;
- **воздух** — CO₂, VOC, температура, влажность;
- **среда** — свет, шум, присутствие, перемещения;
- **приборы** — Prestigio PTH01BT, Redmond RSC-51S, RSP-103S и другие.

Мы расшифровываем закрытые BLE-протоколы, чтобы данные не зависели от чужого
облака, и публикуем результаты так, чтобы их можно было проверить.

## Принципы

1. **Проверяемость** — методика, данные, код и ограничения.
2. **Локальность** — данные дома; облако только если без него нельзя.
3. **Открытость** — протоколы и код открыты; чужие прошивки и персональные данные — нет.
4. **Честность** — «не проверено» пишется прямо.
5. **Связь с книгой** — инструмент помогает понять человека, а не просто собрать числа.
