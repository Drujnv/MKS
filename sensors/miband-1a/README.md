# Mi Band 1A без приложения: BLE -> MQTT -> Home Assistant

> Открытая заметка о том, как забрать данные с **Xiaomi Mi Band 1A** (первое поколение,
> без ключа) через ESP32 и отдать их в Home Assistant. Без облака, аккаунта и телефона.
>
> Публикуется как есть, с ошибками и ограничениями — не как «готовый продукт».

## Что это

Mi Band 1A умеет отдавать по BLE:

- заряд батареи — `FF0C`;
- счётчик шагов — `FF06`;
- историю активности — команда `0x06` в `FF05`, поток в `FF07`;
- «живой» акселерометр — команда `0x12 0x01` в `FF05`, поток в `FF0E`;
- дату/время — `FF0A`.

**Пульсометра у 1A нет.** Пульс, SpO2 и сон в медицинском смысле этот проект не измеряет.

Архитектура:

```
Mi Band 1A --BLE--> ESP32 (R4sGate) --MQTT--> Home Assistant
                         |
                         +--> PostgreSQL: home.readings (source=miband)
```

## Что проверено, а что нет

Проверено:

- UUID сервиса/характеристик и формат 20-байтного `UserInfo` (сверено с pymb1a);
- CRC8 для `UserInfo` — Dallas/Maxim, а не «полином 0x07»; именно на этом
  ломалась авторизация;
- путь `battery`/`steps` -> MQTT `mks/miband/*` -> HA сенсоры;
- исторические значения в PostgreSQL (`source=miband`);
- ESP32-скан: если браслет в эфире, он находится по имени `MI1A`/`MI BAND`
  или по MAC; если браслет занят телефоном/выключен — его нет в эфире.

**Не проверено на живом браслете в момент публикации:** полный цикл
`pair -> UserInfo -> 0x05` на текущем экземпляре, потому что браслет
не рекламировался (см. `docs/TROUBLESHOOTING.md`). Не выдавай это за
подтверждённую авторизацию: код есть, но живого кадра `0x05` мы не видели.

## Быстрый старт

### 1. Найти браслет

```bash
python windows/miband_1a_reader.py --scan 60
```

Почему 60 секунд: Mi Band 1A **не вещает постоянно**. Она появляется в эфире
после нажатия кнопки/встряхивания, после зарядки или после сброса; в обычном
режиме телефон держит соединение, и браслет для других централей невидим.

### 2. Проверить авторизацию

```bash
python windows/miband_1a_reader.py --mac AA:BB:CC:DD:EE:FF --auth
```

Успех — уведомление `0x05` на `FF03`. Отказ — `0x06`. Нет ответа — см.
`docs/TROUBLESHOOTING.md`.

### 3. Забрать историю

```bash
python windows/miband_1a_reader.py --mac AA:BB:CC:DD:EE:FF --fetch
```

### 4. ESP32

Модуль Mi Band живёт в прошивке `R4sGate` (`main/sleepdot.c`, проект MKS).
Он поднимает BLE-соединение по появлению браслета в эфире, пишет `UserInfo`,
читает `FF0C`/`FF06`, публикует MQTT. Подробности — `esp32/README.md`.
