# S-89 в Home Assistant

`homeassistant/s89_mqtt.yaml` — пример MQTT discovery для сенсоров S-89 в HA.

Мост должен публиковать:

```json
mks/oximeter/state
{
  "spo2": 99,
  "pulse": 69,
  "hrv": 210,
  "pi": 18.3,
  "worn": true,
  "measuring": true
}
```

и `mks/oximeter/status` = `online` / `offline` (LWT).

## Что важно

- `spo2`/`pulse` приходят только при валидном кадре; при отсутствии пальца
  публикуй `worn: false` и не выдавай старые значения за новые.
- `pi` — проценты перфузии; в HA это просто число, не «качество сна».
- HRV — значение `[6]` из кадра; не путать с RR-интервалом.
- Если используешь ESP32, см. `../esp32/`.

## Где взять мост

В проекте МКС мост работает на ESP32-C3 R4sGate и публикует данные в MQTT;
этот файл — только HA-часть. Свой мост можно собрать на `s89_protocol.c`.
