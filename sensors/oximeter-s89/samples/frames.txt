# Обезличенные кадры S-89

MAC и личные данные удалены. Все кадры — 20 байт, hex.

## Старт (TX в F1080003)

```
90 02 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```

## Старт-ACK (RX из F1080002)

```
90 02 01 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```

## Как читать

```
[0] 90  заголовок
[1] 02
[2] 03  измерение
[3] 01  палец есть
[4] 63  SpO2 99 %
[5] 45  пульс 69
[6] d2  HRV 210
[7] b7  PI 18.3 %
```
