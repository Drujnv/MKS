# Changelog

## 2026-11-08 — initial public release

- восстановлен протокол S-89: F1080001/2/3, старт `90 02 01` (20 байт);
- подтверждены SpO₂ `[4]`, пульс `[5]`, HRV `[6]`, PI `[7]/10`;
- добавлен Windows reference client на `bleak`;
- добавлен независимый C-парсер/билдер кадров для ESP-IDF;
- добавлен пример MQTT discovery для Home Assistant;
- найдена команда батареи `90 01 02`, добавлен `--battery` (ответ ещё не подтверждён живьём);
- добавлена подписка F1020002 и `--ppg` для ADC/PPG (кадры ещё не подтверждены живьём);
- опубликованы ограничения: нет температуры, PPG и истории; PI/HRV — не медицинские.

Первая версия проверена на живом S-89 и ESP32-C3.
