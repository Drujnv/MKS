# Redmond RSC-51S — CO₂ напрямую по Bluetooth

Станция **Redmond RSC-51S** (CST001, прошивка 136 / ПО 3.21) отдаёт CO₂ только
своему приложению. Здесь — как читать её **напрямую по BLE**, без аккаунта,
облака и интернета, на Windows/Linux/macOS и через ESP32-шлюз.

Часть проекта **MKS** — исследовательской лаборатории вокруг книги
«Многомерный Кристалл Сознания». CO₂ нужен книге как один из параметров среды
для анализа сна и состояния; протокол расшифрован на своём приборе.

## Что проверено

- подключение и разбор кадра;
- CO₂: `ppm = сырое значение + 400` (проверено на свежем воздухе: 406–421 ppm);
- правило прогрева: **первые 10 минут** после включения данные не использовать;
- GATT: сервис `6e400001-…` (NUS-подобный), запись `6e400002-…`, уведомления `6e400003-…`;
- протокол **без шифрования и без настоящей аутентификации** — это важно понимать.

Чего нет: управления станцией, чтения чужого облака, поддержки чужих приборов.

## Быстрый старт (Windows/Linux/macOS)

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r windows/requirements.txt

python windows/rsc51s.py --minutes 10 --out co2.csv
# если нужно — по адресу:
python windows/rsc51s.py --address AA:BB:CC:DD:EE:FF --minutes 60 --out co2.csv
```

Скрипт сам:
1. находит станцию по имени `RSC`/`REDMOND` (или по адресу);
2. подписывается на уведомления **до** команд;
3. делает Just Works-сопряжение (иначе ATT `Insufficient Authentication`);
4. отправляет запуск `01 00` и кадр `55 00 FF <8×FF> AA`;
5. пишет CSV: время, ppm, сырое CO₂, сырую влажность, счётчик, признак «годен».

## ESP32-C3 R4S-шлюз (форк alutov)

RSC-51S — штатное Redmond-устройство: форк
[`alutov/ESP32-R4sGate-for-Redmond`](https://github.com/alutov/ESP32-R4sGate-for-Redmond)
умеет подключаться к станции и отдавать её в MQTT/UI. Наши изменения и порядок
проверки — `r4s-fork/RSC51S-R4S.md`. Отдельный патч не требуется; важны
**сопряжение** и **подписка до команд**.

## Home Assistant

`homeassistant/rsc51s_mqtt.yaml` — пример MQTT-сущностей, если ваш шлюз публикует
CO₂/температуру/влажность. Замените MAC-плейсхолдер на свой.

## Ограничения (честно)

- **первые 10 минут** после включения — прогрев, данные не использовать;
- дальность **3–5 м**; через металлизированное остекление связи нет;
- влажность — **сырое значение**, не проценты: шкала не откалибрована;
- CO₂ — любительский прибор, не метрологическое средство;
- протокол без защиты: показания может прочитать любой, кто рядом;
- часть служебных байтов не расшифрована — не выдумываем.
