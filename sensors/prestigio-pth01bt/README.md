# Prestigio PTH01BT — открытый BLE-протокол и готовые интеграции

Практическое исследование закрытого BLE-протокола датчика **Prestigio PTH01BT**
(температура / влажность / давление / батарея) и готовые способы получать данные:

- **Windows / Linux / macOS** — чистый Python + `bleak`, без облака и приложения;
- **ESP32** — компактный C-декодер для Arduino/ESP-IDF;
- **ESP32-C3 R4S-шлюз** — интеграция в форк
  [`alutov/ESP32-R4sGate-for-Redmond`](https://github.com/alutov/ESP32-R4sGate-for-Redmond):
  приём рекламы, MQTT, HA, UI;
- **Home Assistant** — MQTT-сущности и автоматизации;
- **Prometheus/Grafana** — экспортёр метрик.

Всё, что нужно для повторения: карта протокола, формулы, проверочные данные,
рабочий код, ограничения и честные предупреждения.

> **Контекст проекта MKS.** Этот репозиторий — часть исследовательской
> лаборатории вокруг книги «Многомерный Кристалл Сознания». Датчики, протоколы
> и измерения появились не как самоцель, а чтобы проверять утверждения книги о
> сне, среде и восприятии. Подробнее: [docs/ABOUT-MKS.md](docs/ABOUT-MKS.md).

> **Приватность.** В репозитории нет реальных MAC-адресов, логинов, паролей,
> токенов и путей пользователя. MAC в примерах заменён на `AA:BB:CC:DD:EE:FF`.
> Для работы подставьте MAC своего датчика.

## Быстрый старт

### 1. Windows / Linux / macOS: пассивная реклама (рекомендуется)

```bash
python -m venv .venv
. .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r windows/requirements.txt

# пассивно слушать рекламу; MAC не обязателен
python windows/prestigio_reader.py --scan 30

# если знаете MAC — фильтр по нему
python windows/prestigio_reader.py --mac AA:BB:CC:DD:EE:FF --scan 30
```

Скрипт печатает температуру, влажность, давление и батарею и **не подключается**
к датчику GATT — не занимает BLE-адаптер и не мешает другим устройствам.

### 2. ESP32 (Arduino / ESP-IDF)

Скопируйте `esp32/prestigio_decode.c` и `esp32/prestigio_decode.h` в проект.
На каждый рекламный пакет с company ID `0x01DE` вызовите:

```c
prestigio_data_t d;
if (prestigio_decode_adv(manufacturer_data, manufacturer_len, &d)) {
    // d.temperature_c, d.humidity_percent, d.pressure_hpa, d.battery_percent
}
```

Подробности и пример сканера: `esp32/README.md`.

### 3. ESP32-C3 R4S-шлюз (форк alutov)

В форке уже есть BLE-сканер и MQTT. Добавьте обработчик из
`r4s-fork/PRESTIGIO-R4S.md`: он ловит рекламу по company ID `0x01DE`,
декодирует поля и публикует:

```
r4s0/<mac>/temperature
r4s0/<mac>/humidity
r4s0/<mac>/pressure
r4s0/<mac>/battery
```

Проверено на ESP32-C3: R4S-UI, MQTT и Home Assistant получают значения без
Windows-хоста. Готовый патч-фрагмент и порядок вставки — в документе.

### 4. Home Assistant

Скопируйте `homeassistant/prestigio_mqtt.yaml` в пакет/`configuration.yaml` и
замените MAC-плейсхолдер. Появятся сенсоры температуры, влажности, давления и
батареи. Автоматизации/шаблоны — в том же файле.

### 5. Prometheus

`integrations/prestigio_exporter.py` читает MQTT-топики R4S и отдаёт
`/metrics` на `127.0.0.1:9191`; не занимает BLE. Инструкция — в файле.

## Точность и корреляция

- температура относительно Tuya ZG-227Z: **−0.04 °C**;
- влажность относительно Tuya: **+3.6 п.п.** (коридор датчиков ~10 п.п.);
- формулы: температура **r=0.983–0.991, RMSE 0.29–0.42 °C**, влажность **r=0.923–0.996, RMSE 0.9 %**;
- станция REDMOND теплее на **1.4–1.9 °C**, LifeControl завышает влажность на **+9 п.п.**

Подробно: [docs/ACCURACY.md](docs/ACCURACY.md).

## Ключевые результаты

- реклама (manufacturer data, 15 байт) содержит **температуру, влажность,
  давление и батарею**; GATT-характеристика `0xFB43` — те же поля в 8 байтах;
- поля — **16-битные big-endian слова**, не отдельные байты; именно это ломало
  «побайтовые» попытки;
- формулы проверены на диапазоне **−18…+27 °C** и **50…100 % RH**;
- датчик не имеет кнопки; после сброса питания часто спит и рекламируется редко;
- GATT-подключение монополизирует датчик и зажигает светодиод; для постоянного
  мониторинга используйте пассивную рекламу.
