# Протокол Prestigio PTH01BT

## 1. Идентификация

| Параметр | Значение |
|---|---|
| Модель | Prestigio PTH01BT (OEM, в GAP производитель «Nexturn») |
| Тип | BLE temperature / humidity / pressure / battery |
| Advertising service | `0xFE00` |
| Manufacturer company ID | `0x01DE` |
| GATT service | `0xFA04` |
| GATT characteristic | `0xFB43` |
| GATT access | read, 8 bytes |
| Питание | 2 × AAA |
| Кнопка | **отсутствует** |
| Сброс | вынуть/вставить батарейки |

## 2. Реклама (manufacturer data)

Типичный manufacturer payload (15 байт):

```
01 09 9b 02 01 05 4f 04 10 00 64 03 02 3e 71
```

Разбор:

| Смещение | Поле | Пример | Формула | Результат |
|---|---|---|---|---|
| `raw[0]` | версия/флаги | `0x01` | — | — |
| `raw[1..2]` | `w_temp` BE16 | `0x099b` = 2459 | `t = 0.03017*w - 47.39` | **26.8 °C** |
| `raw[3..4]` | служебное | `0x0201` | — | — |
| `raw[5..6]` | `w_hum` BE16 | `0x054f` = 1359 | `h = 0.0875*w - 59.2` | **59.7 %** |
| `raw[7..9]` | служебное | `04 10 00` | — | — |
| `raw[10]` | battery | `0x64` = 100 | `% = raw[10]` | **100 %** |
| `raw[11..12]` | служебное | `03 02` | — | — |
| `raw[13..14]` | `w_press` BE16 | `0x3e71` = 15985 | `p = w/16` (hPa), в прошивке R4S `w*5/8` в десятых hPa | **999.1 hPa** |

> В `esp32/prestigio_decode.c` и R4S используется расчёт давления `w * 5 / 8`
> в **десятых долях гПа**, затем делится на 10 для hPa. Это эквивалент `w / 16`
> с округлением и совпадает с GATT-полем давления.

### Смещения в ESP-IDF scan result

`scan_result->scan_rst.ble_adv` содержит заголовки рекламы. При сигнатуре
`ble_adv[3..10] = 03 02 00 fe 12 ff de 01` поля находятся по смещениям:

```
ble_adv[12..13]  -> температура
ble_adv[16..17]  -> влажность
ble_adv[21]      -> батарея
ble_adv[24..25]  -> давление
```

Это те же поля, что `raw[1..2]`, `raw[5..6]`, `raw[10]`, `raw[13..14]`
при начале manufacturer payload с `ble_adv[11]`.

## 3. GATT (8 байт)

Подключение к сервису `0xFA04`, чтение `0xFB43`:

```
09 36 05 3e 3e 90 00 64
```

| Смещение | Поле | Формула | Пример |
|---|---|---|---|
| `b[0..1]` | `w1` BE16 | `t = 0.03253*w1 - 52.79` | 23.9 °C |
| `b[2..3]` | `w2` BE16 | `h = 0.09101*w2 - 64.55` | 57.6 % |
| `b[4..5]` | `w3` BE16 | `p = w3 / 16` | 1001.0 hPa |
| `b[6]` | служебное | — | — |
| `b[7]` | battery | `% = b[7]` | 100 % |

Формулы GATT получены по 44 парам «реклама ↔ GATT» и проверены эталонными
датчиками; см. `RESEARCH.md`.

## 4. Ограничения

* формулы эмпирические: уверенный диапазон **−18…+27 °C**, **50…100 % RH**;
  вне диапазона возможна систематическая ошибка;
* давление в рекламе — приближённое, без заводской калибровки;
* BLE не проходит через закрытый металлический холодильник;
* после сброса питания датчик может рекламироваться редко (1 пакет / 20–30 с);
* GATT-подключение **монополизирует** устройство: пока сессия активна, датчик
  не рекламируется, светодиод горит, другие приложения его не видят;
* реальный MAC и другие идентификаторы в публичных примерах заменены.

## 5. Рекомендуемый режим

Для постоянного мониторинга — **только пассивная реклама**. GATT использовать
для разового замера/калибровки, после чего обязательно закрывать соединение.
