# Как расшифровывали и проверяли

## 1. Задача

Датчик Prestigio PTH01BT не публикует протокол; управляется только фирменным
приложением (LifeControl-подобный OEM, производитель в GAP — Nexturn).
Нужно было получить показания **локально**, без облака, на разных платформах
(Windows, Linux, ESP32).

## 2. Метод

1. Захват рекламных пакетов и GATT-обмена штатными BLE-средствами.
2. Сопоставление рекламы и GATT: один и тот же момент, 44 пары.
3. Проверка полей как **16-битных big-endian слов**, а не байтов.
4. Линейная регрессия:
   * температура: `t = 0.03017 * w_temp - 47.39` (r = 0.991, RMSE 0.29 °C);
   * влажность: `h = 0.0875 * w_hum - 59.2` (r = 0.996, RMSE 0.9 %);
   * давление: `p = w_press / 16` hPa;
   * батарея: `raw[10]` (в GATT — `b[7]`).
5. Проверка на эталонах: LifeControl MCLH-08, Tuya ZG-227Z, станция REDMOND
   RSC-51S, а также «морозилка» (−18 °C), салфетка/высыхание (влажность).

## 3. Результаты проверки (2 минуты, рядом 4 датчика)

| Датчик | Температура | Влажность |
|---|---:|---:|
| Prestigio | 24.99 °C | 56.7 % |
| Tuya ZG-227Z | 25.02 °C | 53.1 % |
| LifeControl MCLH-08 | 24.47 °C | 62.1 % |
| REDMOND RSC-51S | 26.40 °C | 51.5 % |

Попарные смещения:

```
Prestigio - Tuya        dt = -0.04 °C   dh = +3.6 %
Prestigio - LifeControl dt = +0.52 °C   dh = -5.4 %
Prestigio - REDMOND     dt = -1.41 °C   dh = +5.2 %
LifeControl - Tuya      dt = -0.56 °C   dh = +9.0 %
REDMOND - Tuya          dt = -1.38 °C   dh = +1.7 %
```

Prestigio садится между двумя Zigbee-датчиками — декодер согласован.

## 4. GATT-проверка

* сервис `0xFA04`, характеристика `0xFB43`, 8 байт;
* поля — 16-битные слова:
  `t = 0.03253*w1 - 52.79`, `h = 0.09101*w2 - 64.55`, `p = w3 / 16`;
* после чтения соединение обязательно закрывать: иначе датчик перестаёт
  рекламироваться и «пропадает» для других систем.

## 5. Проверка на платформах

| Платформа | Статус |
|---|---|
| Windows (Python + bleak) | пассивная реклама и GATT проверены |
| ESP32 (Arduino/ESP-IDF) | декодер рекламы, компилируется, проверен на C3 |
| ESP32-C3 R4S-шлюз (форк alutov) | реклама → MQTT → HA, проверено на живом датчике |
| Home Assistant | MQTT-сущности, значения совпадают |
| Linux/macOS | тот же bleak-скрипт; проверялась логика декодера |

## 6. Честные ограничения

* формулы эмпирические; за пределами −18…+27 °C и 50…100 % RH не гарантируются;
* давление проверено по порядку величины, без лабораторной калибровки;
* датчик не имеет кнопки; после сброса питания спит и рекламируется редко;
* BLE-сигнал не проходит через закрытый холодильник;
* GATT-сессия монополизирует устройство; для постоянного сбора — только реклама;
* в публичных примерах MAC и другие идентификаторы заменены.

## 7. Что не входит в репозиторий

* реальные MAC, логины, пароли, токены и пути пользователя;
* прошивки и бинарники вендора;
* персональные данные и переписка.
