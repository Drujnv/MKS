# Точность, корреляция и систематические смещения

Источники: натурная сверка четырёх датчиков (18.10.2026), калибровки
«морозилка → комната», 44 пары «реклама ↔ GATT». Все замеры — на одном столе,
установившийся режим, средние за 2 минуты.

## 1. Средние значения (эталонная сверка)

| Датчик | Температура, °C | Влажность, % | Примечание |
|---|---:|---:|---|
| **Prestigio PTH01BT** | **24.99** | **56.7** | наш декодер GATT `FB43` |
| Tuya ZG-227Z | 25.02 | 53.1 | Zigbee2MQTT, эталон сравнения |
| LifeControl MCLH-08 | 24.47 | 62.1 | Zigbee2MQTT, инерция корпуса ~20 мин |
| REDMOND RSC-51S | 26.40 | 51.5 | стоит у техники, систематически теплее |

## 2. Попарные смещения (A − B)

| Пара | Δt, °C | Δh, % |
|---|---:|---:|
| Prestigio − Tuya | **−0.04** | **+3.6** |
| Prestigio − LifeControl | +0.52 | −5.4 |
| Prestigio − REDMOND | −1.41 | +5.2 |
| LifeControl − Tuya | −0.56 | +9.0 |
| REDMOND − Tuya | −1.38 | +1.7 |
| LifeControl − REDMOND | −1.93 | +10.7 |

**Что это значит:**

* Prestigio по температуре **практически совпадает с Tuya** (−0.04 °C);
* влажность Prestigio выше Tuya на **+3.6 п.п.** (в пределах коридора датчиков);
* LifeControl завышает влажность на **+9 п.п.** — его влажностный канал нельзя
  считать эталоном;
* станция REDMOND стабильно теплее на **1.4–1.9 °C** из-за позиции у техники;
  для CO₂/давления её можно использовать, для температуры — с поправкой.

## 3. Корреляция формул (калибровка)

| Канал | Формула | r | RMSE |
|---|---|---:|---:|
| GATT: температура | `t = 0.03253·w1 − 52.79` | **0.983** | **0.42 °C** |
| GATT: влажность | `h = 0.09101·w2 − 64.55` | **0.923** | проверено салфеткой/высыханием |
| Реклама: температура | `t = 0.03017·w_temp − 47.39` | **0.991** | **0.29 °C** |
| Реклама: влажность | `h = 0.0875·w_hum − 59.2` | **0.996** | **0.9 %** |
| Давление | `p = w_press / 16` | — | сверено по порядку величины |

44 пары «реклама ↔ GATT»; отдельно проверены точки около −18 °C (морозилка)
и 50–100 % RH (салфетка/высыхание).

## 4. Насколько «врёт» — коротко

* **температура:** в среднем **−0.04 °C** относительно Tuya; относительно
  LifeControl +0.52 °C; относительно станции −1.41 °C (станция теплее);
* **влажность:** **+3.6 п.п.** к Tuya; −5.4 п.п. к LifeControl; +5.2 п.п.
  к станции; разброс между датчиками в комнате ~10 п.п.;
* **давление:** абсолютная калибровка не проводилась; используйте как
  относительный тренд, не как эталон;
* **батарея:** дискретная, 1 %; на 100 % долго держится.

## 5. Ограничения и замечания

* формулы эмпирические; вне **−18…+27 °C** и **50…100 % RH** не гарантируются;
* у датчика нет кнопки; после сброса питания он спит и рекламируется редко;
* GATT-подключение монополизирует датчик (светодиод горит, реклама пропадает);
* BLE не проходит через закрытый холодильник — это физика, не поломка;
* при разнесении датчиков по квартире учитывайте **поправки из таблицы 2**,
  а не абсолютные значения;
* для сна/CO₂ важнее тренд и корреляция, чем абсолютная точность.

## 6. Практические поправки

Если нужен «эталон Tuya»:

```
T_tuya ≈ T_prestigio + 0.04
H_tuya ≈ H_prestigio - 3.6
```

Если нужен «эталон LifeControl» (не рекомендуется для влажности):

```
T_lc ≈ T_prestigio - 0.52
H_lc ≈ H_prestigio + 5.4
```

Станция REDMOND:

```
T_redmond ≈ T_prestigio + 1.41   (станция теплее)
```
